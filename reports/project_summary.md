# Sonoran Cycles Project Summary

## Project Purpose

This project simulates the supply chain operations of a fictional premium bicycle manufacturer. It was built to demonstrate demand planning, inventory analysis, replenishment logic, SQL analysis, and dashboard planning.

## Analytical Focus

The analysis focuses on how customer demand, inventory availability, supplier replenishment, and forecast accuracy affect business performance.

## Core Metrics

- Booked Revenue
- Fulfilled Revenue
- Requested Units
- Fulfilled Units
- Backordered Units
- Service Level
- Backorder Rate
- Forecast WAPE
- Forecast Bias
- Open Purchase Order Units
- Stockout Days

## Key Analytical Themes

1. Demand is concentrated across certain models, SKUs, channels, and dealer tiers.
2. Fulfillment performance depends on SKU-level inventory availability.
3. Backorders reveal where demand exceeded available supply.
4. Supplier lead times affect replenishment timing and open PO exposure.
5. Forecast accuracy can be evaluated by model and month using WAPE and bias.

## Project Stack

- Python simulation engine
- CSV output tables
- SQLite database
- SQL business analysis
- Power BI dashboard design documentation
